Service Functions

WRITE addExpense

▶

Adds a new financial expense to the user's expense tracker.

INSERTexpenses table
Input: { description: string, amount: number, category: string } Output: { success: boolean, message: string }

DELETE deleteExpense

▶

Deletes an expense by its ID.

DELETEexpenses table
Input: { expenseId: string } Output: { success: boolean, message: string }

READ getExpenses

▶

Retrieves expenses with optional filtering by category and date range.

SELECTexpenses table
Input: { category?: string, startDate?: string, endDate?: string } Output: [{ id, date, description, amount, category }]

COMPUTE getSpendingInsights

▶

Analyzes spending data: totals, averages, top category, and category breakdown.

AGGREGATEvia getExpenses
Input: { category?: string, startDate?: string, endDate?: string } Output: { totalSpending, averageTransaction, transactionCount, topCategory, topCategoryAmount, categoryBreakdown: [{ category, amount, percentage, count }] }

COMPUTE getSpendingTrends

▶

Returns spending data grouped by day, week, or month in chart-ready format.

AGGREGATEvia getExpenses
Input: { groupBy?: "day" | "week" | "month", category?: string } Output: { labels: string[], datasets: [{ label, data: number[] }] }

WRITE setBudget

▶

Sets or updates a budget amount for a specific spending category (upsert).

UPSERTbudgets table
Input: { category: string, amount: number } Output: { success: boolean, message: string, category: string, amount: number }

DELETE deleteBudget

▶

Deletes a budget for a specific category.

DELETEbudgets table
Input: { category: string } Output: { success: boolean, message: string }

READ getBudgetOverview

▶

Returns budget overview comparing budgets vs actual spending per category.

SELECTbudgets + expenses
Input: { startDate?: string, endDate?: string } Output: [{ category, budgetAmount, actualAmount, transactionCount }]

Authentication Security

Supabase Auth flows and middleware route protection.

Sign-Up Flow
sequenceDiagram
    participant U as User
    participant SP as /auth/signup
    participant SB as Supabase Auth
    participant EM as Email
    participant CB as /auth/callback
    participant CH as /chat

    U->>SP: Fill email + password
    SP->>SB: signUp({ email, password, emailRedirectTo })
    SB->>EM: Send confirmation link
    SP-->>U: Show "Check your email" screen
    U->>EM: Click confirmation link
    EM->>CB: GET /auth/callback?code=xxx
    CB->>SB: exchangeCodeForSession(code)
    SB-->>CB: Session created
    CB->>CH: Redirect to /chat
Login Flow
sequenceDiagram
    participant U as User
    participant LP as /auth/login
    participant SB as Supabase Auth
    participant CH as /chat

    U->>LP: Fill email + password
    LP->>SB: signInWithPassword({ email, password })
    alt Success
        SB-->>LP: Session cookie set
        LP->>CH: router.push("/chat") + refresh
    else Error
        SB-->>LP: Error message
        LP-->>U: Display error
    end
